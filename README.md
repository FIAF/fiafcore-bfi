# FIAFcore [BFI]

Conformation of BFI data to FIAFcore.

**Deployment**

This transformation has been built using [Python](https://www.python.org/) with [uv](https://docs.astral.sh/uv/) as dependancy manager. Once relevant XML data has been placed into the `xml` subdirectory, transformation can be executed with the following command.

```sh
uv run transform.py
```
